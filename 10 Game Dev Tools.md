**Engines**

**ENIGMA:** [**https://enigma-dev.org/**](https://enigma-dev.org/)

Info gathered from [https://enginesdatabase.com/engine/enigma/](https://enginesdatabase.com/engine/enigma/) and [https://enigma-dev.org/](https://enigma-dev.org/)

An open-source game development software designed to be beginner-friendly and cross-platform. It is compatible with Game Maker, offering both a drag-and-drop coding option as well as its own coding language. This language, EDL (Enigma Development Language), is a combination of C++ and GML (Game Maker Language).

Pros:

- Free
- Beginner-friendly
- Cross-platform
- Multiple coding options
- Fast processing
- Compatible with Game Maker
- Small file size

Cons:

- Unique coding language
- Website doesn’t seem to be regularly updated

**Source Engine:** [**https://developer.valvesoftware.com/wiki/Source**](https://developer.valvesoftware.com/wiki/Source)

Info gathered from [https://enginesdatabase.com/engine/source\_engine/](https://enginesdatabase.com/engine/source_engine/), [https://developer.valvesoftware.com/wiki/Source](https://developer.valvesoftware.com/wiki/Source), and [https://www.reddit.com/r/SourceEngine/comments/62vf5t/how\_much\_is\_it\_to\_buy\_the\_source\_engine\_license/](https://www.reddit.com/r/SourceEngine/comments/62vf5t/how_much_is_it_to_buy_the_source_engine_license/)

A 3D game engine developed by Valve that once was used by larger companies but is now mostly used by indie developers. It offers various physics and visual features, such as vehicle parameters (wheel interaction with environment, max speed, etc.). It was written in C++, and allows the use of C++, C, Lua, and Squirrel.

Pros:

- Cross-platform
- Moddable
- Actively maintained
- Noncommercial use is free
- Variety of rendering, physics, AI, and audio features

Cons:

- Large file size
- Commercial use requires a license, price depends on project
- Features may be outdated
- Limited to 3D

**Gondwana Game Engine:** [**https://github.com/Isthimius/Gondwana/tree/master**](https://github.com/Isthimius/Gondwana/tree/master)

Info gathered from [https://enginesdatabase.com/engine/gondwana/](https://enginesdatabase.com/engine/gondwana/) and [https://github.com/Isthimius/Gondwana/blob/master/README.md](https://github.com/Isthimius/Gondwana/blob/master/README.md)

A “code-first” open-source engine for 2D and 2.5D games that gives developers detailed control over features like movement and scene composition. It has a predictable and visible rendering process for developers to adjust as needed. It uses C# and is object-oriented. It does not require a separate editor program to function.

Pros:

- Free
- Small file size
- Cross-platform
- Transparent rendering process
- Feature variety

Cons:

- Limited to 2D and 2.5D
- Still actively developing
- Not all-encompassing

**Ren’Py:** [**https://www.renpy.org/**](https://www.renpy.org/)

Info gathered from [https://enginesdatabase.com/engine/renpy/](https://enginesdatabase.com/engine/renpy/) and [https://www.renpy.org/](https://www.renpy.org/)

An open-source visual novel engine used for thousands of games that are writing-heavy, such as life simulations. It uses Python and can be paired with any text editor to write scripts. Assets and features, like scene transitions and interfaces, are very customizable.

Pros:

- Free
- Small file size
- Cross-platform
- Extensive documentation and guides
- Customizability
- Simplistic but very functional scripting

Cons:

- Limited to visual novels/life simulations
- Slow programming language

**HaxeFlixel:** [**https://haxeflixel.com/**](https://haxeflixel.com/)

Info gathered from [https://enginesdatabase.com/engine/haxeflixel/](https://enginesdatabase.com/engine/haxeflixel/), [https://haxeflixel.com/](https://haxeflixel.com/), and [https://haxe.fandom.com/wiki/HaxeFlixel](https://haxe.fandom.com/wiki/HaxeFlixel)

A cross-platform and open-source game engine built from Haxe (its coding language), OpenFL, and Flixel. It has a handful of features, including object grouping, simple collision, and camera capacity for split screen.

Pros:

- Documentation of tutorials and community resources
- Free
- Small file size
- Cross-platform

Cons:

- 3D capabilities seem limited

**Gosu:** [**https://www.libgosu.org/index.html**](https://www.libgosu.org/index.html)

Info gathered from [https://enginesdatabase.com/engine/gosu/](https://enginesdatabase.com/engine/gosu/), [https://www.libgosu.org/index.html](https://www.libgosu.org/index.html), and [https://github.com/gosu/gosu/wiki/](https://github.com/gosu/gosu/wiki/)

A 2D, open-source game development library that is largely used to learn Ruby or in short game development competitions, like game jams. It is compatible with Ruby and C++, having dependencies on other low-level programs such as SDL 2.

Pros:

- Free
- Small file size
- Cross-platform
- Educational
- Documentation including tutorials in multiple languages and forums

Cons:

- 3D capabilities seem limited
- Not made for long-term or in-depth game development

**Tools**

**Spine:** [**https://esotericsoftware.com/**](https://esotericsoftware.com/)

Info gathered from [https://esotericsoftware.com/](https://esotericsoftware.com/)

A 2D skeletal animation software that is compatible with various game toolkits and programming languages, including Unity, HaxeFlixel, C++, and TypeScript. It has features like interpolation graphs, paths, and various ones relating to bones. It takes up less space and time than frame-by-frame animation.

Pros:

- Efficient
- Cross-platform
- Lightweight exported files
- Game engine compatibility

Cons:

- Usage past the free trial requires a license, prices range from $69-2500+
- Limited to skeletal animation

**FMOD:** [**https://www.fmod.com/**](https://www.fmod.com/)

Info gathered from [https://www.fmod.com/](https://www.fmod.com/)

A professional audio engine utilized by major companies and game studios. It has four main parts: FMOD Studio (far-reaching audio editor and playback engine), FMOD for Unity (engine integrated directly into Unity), FMOD Core (lightweight version of the standard engine), and FMOD.io (high-quality audio assets library).

Pros:

- Cross-platform
- FMOD Studio is free for companies that make under $200k
- Resources available for all levels of experience

Cons:

- Audio assets individually cost money
- FMOD Studio’s licenses range in price from $2k-18k per game

**Krita:** [**https://krita.org/en/**](https://krita.org/en/)

Info gathered from [https://krita.org/en/](https://krita.org/en/)

An open-source art program with an understandable and customizable interface. It has hundreds of assets and features, including brushes, stabilizers, and brush engines. Assets can also be imported. It supports 2D frame-by-frame animation.

Pros:

- Free
- Cross-platform
- User manual and documented resources
- Compatible with Python scripting

Cons:

- Personal distaste for the brush presets tab

**SpriteLoop:** [**https://balkanramgames.itch.io/spriteloop**](https://balkanramgames.itch.io/spriteloop)

Info gathered from [https://balkanramgames.itch.io/spriteloop](https://balkanramgames.itch.io/spriteloop)

A 2D sprite animation software with a variety of features, such as rigging, tween animation, and timeline adjustments. It offers multiple export options, like spritesheets and GIFs.

Pros:

- Free
- Cross-platform
- Imports compatible with Krita and Photoshop (using plugins)
- Lightweight

Cons:

- Early in development
- Potential minor issues with installation
